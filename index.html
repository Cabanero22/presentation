talk about the key features of TypeScript and show its advantages through examples.

TypeScript — is a superset of JavaScript with the addition of static typing.

Detecting errors in code without running it is referred to as static checking. TypeScript checks a program for errors before execution, and does so based on the kinds of values, making it a static type checker.

  • TypeScript was developed by Microsoft and was introduced in 2012.
  • The developer of TypeScript is Anders Hejlsberg, who previously created Turbo Pascal, Delphi and C#.
  • The language specifications are open and published under the Open Web Foundation Specification Agreement (Ovf 1.0).
Why do we need use TypeScript?

Disadvantages of javascript:

  • Type errors are detected only in runtime.
  • The difficulty of supporting large projects.
  • It's easy to make typos and implicit bugs.
  • Lack of strict structure.
  • Problems with auto-completion and documentation.
  • The IDE cannot accurately predict the types of variables. Hints and code navigation are worse.

Advantages of typescript:

  • Static typing helps to find errors at the development stage before code execution.
  • Improves code readability and maintainability.
  • It is suitable for large projects due to its strict structure.
  • Improved IDE support (auto-completion, refactoring).
  • JavaScript compatibility (any JS code is a valid TS code).
Types and syntax

In addition to all the basic types that JavaScript has, TypeScript has special types:

  • Any
  • Unknown
  • Void
  • Never

Explicit indication of types

							
								const name: string = 'Alex';
								const age: number = 25;
								let a: any = 'string';
								a = 10;

								function hello(name: unknown): void {
									if(typeof name === 'string') {
										console.log('Hello' + ' ' + name)
									};
								}

								function throwError(message: string): never {
								  throw new Error(message);
								}

Types of objects and arrays

							
								type Person = { name: string; age: number }
								const person: Person = { name: 'Bob', age: 25 }

								interface User {
									id: number,
									name: string,
									email?: string // optional property
								}
								const user1: User = { id: 1, name: Jane }

								const fruits: string[] = ['apple', 'banana', 'orange'];
								const numbers: Array <Any> = [1, true, 'red', null];
Union types and intersections

Union types

							
								function printId(id: number | string) {
  								console.log(`ID: ${id}`);
								}

								printId(101);      // ✅
								printId("abc123"); // ✅
								printId(true);     // ❌ Error: boolean is not a number | string

Intersection

							
								type User = {
									name: string;
									age: number;
								};

								type Admin = { role: string };

								type SuperUser = User & Admin;

								const superUser: SuperUser = {
									name: "Alice",
									age: 30,
									role: "admin",
								};
Classes in TypeScript

A class is both a value and a type

							
								class Car {
									public brand: string,
									private year: number

									constructor(brand: string, year: number) {
									this.brand = brand;
									this.year = year;
									}
								}

								// Using a class as a type
								const myCar: Car = new Car("Toyota", 2023);

In the classes use the following access modifiers:

  • Public
  • Private
  • Protected
							
								class Person {
								name: string;        // Public property (by default)
								private age: number; // Private (access only inside the class)

								constructor(name: string, age: number) {
									this.name = name;
									this.age = age;
								}

								public greet() {     // Public method
									console.log(`Hello, I'm ${this.name}`);
								}
							}
							
						
							
								class Employee extends Person {
								protected salary: number;  // Available in subclasses

								constructor(name: string, age: number, salary: number) {
									super(name, age);
									this.salary = salary;
								}

								showSalary() {
									console.log(this.salary);  // ✅ Access to the protected field
									// console.log(this.age);  // ❌ Error: private from parent
								}
							}
Utility types — pre-built tools for type transformations.

Purpose of use:

  • Simplify working with types.
  • Increased code reuse.
  • Reducing the likelihood of errors when working with types.
Partial <Type> — makes all type properties optional. 
							
								interface User {
									name: string;
									age: number;
								}

								type PartialUser = Partial<User>;

								// {
								// 	name?: string;
								// 	age?: number;
								// }
Pick <Type, Keys> — creates a new type containing only the specified keys from the Type. 
							
								interface Todo {
									title: string;
									description: string;
									completed: boolean;
								}
								type TodoPreview = Pick<Todo, "title" | "completed">;

								// {
								//	title: string;
								//  completed: boolean;
								// }
Record <Keys, Type> — creates an object type where keys are of type <Keys> and values are of type <Type>. 
							
								type Colors = "red" | "green" | "blue";

								type RGB = Record<Colors, number>;

								// { red: number; green: number; blue: number; }
Exclude <UnionType, ExcludedMembers> — excludes the specified union types. 
							
								type T0 = Exclude<"a" | "b" | "c", "a">; // "b" | "c"
Generics — universal types for creating flexible code.
Generics allows you to create components (functions, classes, interfaces) that can work with any type of data, while maintaining strict typing.

How do Generics work?

							
								function identity<T>(arg: T): T {
  								return arg;
								}

<T> is a type parameter, where T is a type symbol (you can use any name).

Also, we can specify several type parameters

							
								function combine<T, U>(first: T, second: U): [T, U] {
  								return [first, second];
								}

								const result = combine(1, "test"); // [1, "test"]

We can limit the allowed types using the "extends" or "keyof" keyword. Or we can combine it.

							
								function getKey<T extends object, K extends keyof T>
								(obj: T, key: K): T[K] {
  								return obj[key];
								}

								const user = { id: 1, name: "Alice" };
								const id = getKey(user, "id"); // id: number
								const name = getKey(user, "name"); // name: string

Advantages of using generics:

  • Flexibility
  • Type safety
  • Improved readability
  • Code reuse
